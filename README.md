# Security Event Risk Dashboard

A Flask-based dashboard for tracking and prioritizing security events using rule-based risk scoring.

## Features

- Flask web dashboard
- SQLite database with SQLAlchemy
- Rule-based risk scoring
- REST API for retrieving and creating security events
- Data seeding script

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
